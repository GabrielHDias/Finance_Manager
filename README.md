# Finance Manager

##  Sobre o projeto

Finance Manager é uma aplicação Full Stack para gerenciamento financeiro pessoal.

O projeto está sendo desenvolvido com foco em boas práticas de engenharia de software, arquitetura de software e desenvolvimento Full Stack utilizando Java, Spring Boot, React e Next.js.

Além de resolver um problema real, o projeto tem como objetivo consolidar conhecimentos técnicos e servir como portfólio profissional.

---

##  Objetivos

### Objetivo do software

- Gerenciar receitas e despesas
- Organizar contas financeiras
- Gerar dashboards financeiros
- Importar extratos CSV

### Objetivos de aprendizado

- Aprender Spring Boot
- Aprender React e Next.js
- Aprender PostgreSQL
- Aprender Docker
- Aprender testes automatizados
- Construir um projeto de portfólio profissional
